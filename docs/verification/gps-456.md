# GPS: evidencia original y segmentos medidos (#456)

Una ronda real de Maquinaria duró 28 minutos, con 14 escaneos y solo cuatro posiciones de seguimiento conservadas. La API descartaba las lecturas por encima del umbral de precisión antes de almacenarlas. El PDF unía posiciones separadas por minutos sin registro con rectas punteadas y flechas; además sumaba esas rectas a la distancia.

Ahora se conservan las posiciones originales de rondas autorizadas, con su precisión. Consentimiento, ventana de ronda, validación DTO, idempotencia y RLS se mantienen. La calidad se aplica al leer: un punto impreciso, un salto imposible o un vacío de tiempo separan los segmentos. El mapa web y el PDF reciben esos segmentos separados; no se dibujan conectores ni flechas sobre vacíos ni se suman sus metros. Los escaneos anómalos permanecen como marcas y en la bitácora, sin líneas que puedan confundirse con recorrido.

La ruta y las coordenadas de los NFC no cambian. No se promedian, ajustan o inventan posiciones para coincidir con ellos. La captura nativa no cambia: esta corrección de servidor/web no requiere un nuevo AAB. No permite recuperar lecturas descartadas anteriormente ni garantizar precisión del receptor bajo techo; verificar la siguiente ronda real sigue siendo necesario.

Validación:

- Regresiones de persistencia y distancia fallaron antes de la corrección (tres fallos observados).
- 2.736 pruebas unitarias API correctas (dos omitidas según configuración previa), 988 pruebas web correctas; tipos, lint y compilación API/web.
- Prueba en PostgreSQL real, empresa aislada: se conservan dos lecturas, incluida una de precisión insuficiente; otra empresa no puede leerlas. Rollback comprobado, sin ronda ni evidencias permanentes, sin envío de correo.
- PDF completo regenerado con datos reales, fuera de la caché productiva durante la revisión: cuatro posiciones, tres segmentos (solo uno permite medir distancia), 21 fotos incluidas y ninguna omitida, 11 páginas, aproximadamente 4,3 MB. Comparación visual de la página del mapa antes/después, sin rutas ficticias sobre los vacíos.
- Datos de origen, coordenadas, fotografías e identificadores de la ronda se guardan fuera del repositorio. La copia previa del informe se conserva antes de renovar su caché.

## Despliegue verificado

Código ejecutado: `8cd0856`. Imágenes API y web compiladas manualmente y aplicadas tras comprobar las cinco empresas sin rondas activas ni cierres de evidencia pendientes. Readiness confirma PostgreSQL, Redis y cola de escaneos operativos; PostgreSQL y Redis no se recrearon. Copias de rollback de imágenes y del PDF anterior conservadas fuera del repositorio.

Se renovó la caché de la ronda afectada con el servicio real desplegado. Endpoint y PDF coinciden en tres segmentos aislados y 3,3 metros efectivamente medidos; el resto de la ronda sigue sin un recorrido GPS acreditable. Informe final: 21 fotos incluidas, cero omitidas, 2.120.189 bytes. No se reenvió correo adicional.

Las cuentas temporales de importación de ambas empresas se desactivaron y se cerraron las sesiones conocidas de QA. Los dos commits de código no registran ejecuciones de GitHub Actions asociadas.
